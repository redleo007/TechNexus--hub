# EventZ Manager - Event Management Platform

EventZ Manager is a modern and responsive event management web application developed using React.js. The platform helps users create, manage, and explore events through an intuitive user interface and smooth user experience.

## Live Demo

https://eventz-manager.vercel.app/

## GitHub Repository

https://github.com/redleo007/Event-Manager

## Features

- Event creation and management
- Responsive modern user interface
- Interactive event cards and layouts
- Smooth navigation and user experience
- Dynamic event display
- Mobile-friendly design
- Fast frontend performance
- Clean component-based architecture
